# Maison Éclat – Projet e-commerce

## Présentation du projet

**Maison Éclat** est un projet réalisé dans le cadre de notre formation. L'objectif est de développer une boutique en ligne dédiée aux produits de beauté et de soins, en utilisant plusieurs technologies.

## Gestion du catalogue avec Strapi

Nous avons utilisé **Strapi** pour créer et gérer le catalogue de produits de la boutique, notamment les produits et leurs catégories.

Le CMS permet de centraliser les données et de les rendre accessibles à travers une API REST.

Dépôt GitHub du projet Strapi :
[https://github.com/Maarii908/cms-headless](https://github.com/Maarii908/cms-headless)

## Manipulation des données avec l'API et Postman

Nous avons utilisé **Postman** pour tester et manipuler les données exposées par l'API Strapi.

Cela nous a permis de :

- Consulter la liste des produits.
- Récupérer les informations détaillées d'un produit.
- Ajouter de nouveaux produits.
- Modifier les informations des produits.
- Supprimer des produits.
- Tester les endpoints de l'API et vérifier les réponses du serveur.

Cette étape nous a permis de comprendre le fonctionnement d'une API REST et les échanges de données avec Strapi.

## Développement de la boutique Maison Éclat

Nous avons développé l'application e-commerce avec **Symfony et PHP**. La boutique exploite les données du catalogue géré dans Strapi pour afficher les produits et permettre aux utilisateurs de gérer leur panier.

## Technologies utilisées

- Symfony et PHP
- Strapi
- Postman
- Docker et Docker Compose
- Twig
- HTML, CSS et JavaScript

## Objectif pédagogique

Ce projet nous a permis de mettre en pratique le développement d'une application web, la gestion de contenu avec un CMS Strapi, la manipulation d'une API REST avec Postman et la mise en place d'un environnement de développement avec Docker.
